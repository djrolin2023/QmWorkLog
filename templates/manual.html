使用手册

本手册帮助用户快速掌握乾明工作台账系统的各项功能，从运行环境、获取安装到登录、录入台账与智能总结，按章节对照查阅即可上手。

一、运行环境要求

① 安装路径

默认安装到 D:\QmWorkLog（若计算机无 D 盘，则自动改为 C:\QmWorkLog）。程序仅读写自身目录，无需管理员权限。

② 数据规模

台账与图片越多占用空间越大，建议定期归档与备份，避免磁盘写满。

③ 网络

纯本地应用，无需联网即可运行；仅更新下载、扫码联系等需访问外网。

二、各系统如何获取本系统

本系统提供编译好的安装包与源代码两种方式获取，按所用操作系统选择即可。

Windows

  1. 安装包（推荐）：下载 QmWorkLog_vX.X.X.X.exe，双击运行，按向导选择安装目录（默认 D:\QmWorkLog）即可。
  2. 便携版：下载解压后直接运行 QmWorkLog.exe，数据自动保存在程序所在目录，可放在 U 盘随身携带。
  3. 源码运行：克隆仓库后，使用 Python 3.10+ 创建虚拟环境并安装依赖，执行 python app.py 启动服务（见下方「从源码获取」）。

Linux（Debian / Ubuntu 等）

  1. deb 包：下载 QmWorkLog_X.X.X.X_amd64.deb，执行 sudo dpkg -i QmWorkLog_X.X.X.X_amd64.deb 安装，菜单或命令 qmworklog 启动。
  2. 源码运行：安装 python3-venv、python3-pip，克隆仓库后 pip install -r requirements.txt，再 python3 app.py。

macOS

  1. dmg 包：下载 QmWorkLog-X.X.X.X.dmg，打开后将 QmWorkLog.app 拖入「应用程序」即可。
  2. 源码运行：安装 Homebrew 与 Python 3，克隆仓库后 pip install -r requirements.txt，再 python3 app.py。

① 从源码获取

本项目托管于 GitHub（https://github.com/djrolin2023/QmWorkLog）。拉取命令：
git clone https://github.com/djrolin2023/QmWorkLog.git
进入目录后 git pull 可获取最新更新。

② 下载地址

正式发布的安装包见 GitHub 仓库的 Releases 页面，源码见仓库主分支。

三、登录与基本操作

  1. 打开系统：在浏览器输入系统地址（局域网或外网地址）进入登录页。
  2. 账号登录：输入账号与密码。默认管理员账号 admin / admin，首次使用请务必修改密码。
  3. 记住账号：勾选"记住账号"可缓存用户名，密码不会明文保存。
  4. 退出登录：点击右上角用户名 → "退出登录"。
  5. 切换主题：右上角"深色模式"按钮可在浅色 / 深色主题间切换，偏好会被记住。

四、工作台账录入

台账是系统的核心数据，按"类型 + 日期"组织一条工作记录。

  1. 在左侧菜单点击「工作台账」，进入台账页。
  2. 选择台账类型（如安保巡查、设备维护等，类型在「台账管理」中维护）。
  3. 选择日期，填写工作内容。
  4. 点击上传图片添加现场照片，支持多张；点击图片可查看原图。
  5. 点击保存提交。同一类型同一天可追加多条记录。

小贴士

图片用于留痕，建议清晰、命名规范；单张过大将影响加载速度。

五、台账管理

在「台账管理」中维护台账类型（如新增"消防演练""访客登记"等）。

  1. 点击新增类型，填写类型名称与说明。
  2. 可对已有类型进行编辑 / 删除；删除类型不会删除其历史台账（可归档恢复）。
  3. 导入导出时若缺少对应类型，系统会给出引导并自动创建。

六、智能总结

基于台账内容自动生成周期总结，减少手工汇总工作量。

  1. 进入「智能总结」，选择类型、年份与周期（年度 / 月度 / 自定义）。
  2. 点击生成总结，系统读取该周期内的台账生成报告。
  3. 支持多种总结视角，可复制文本用于上报或存档。

七、数据大屏

「数据大屏」以可视化方式呈现整体情况，打开即自动同步索引。

  1. 环形占比：各类型台账占比一目了然。
  2. 类型分布：不同维度的数量统计。
  3. 月度趋势：台账数量随时间的变化曲线。
  4. 若台账文件被外部改动，刷新大屏即可更新索引。

八、归档管理

对历史台账按需归档，便于长期保存与恢复。

  1. 在「归档管理」中选择类型与年份执行归档。
  2. 归档后可下载归档文件留存。
  3. 误删的台账可一键从归档恢复，数据不丢失。

九、导入导出

用于数据备份、交接与上报。

  1. 整库备份：导出完整数据库文件，建议定期执行并异地留存。
  2. 导入：选择备份文件恢复到系统（导入前请确认版本兼容）。
  3. 按年 / 类型导出：用于局部数据上报。

⚠ 警告

导入会覆盖或合并数据，操作前请先整库备份。

十一、系统设置

集中维护公司与品牌信息、基础参数。

  1. 进入「系统设置」，修改公司名称、LOGO 等展示信息。
  2. 设置会即时生效，影响打印模板与导出文档的页眉页脚。

十二、常见问题

① 打不开系统

确认服务已启动；检查浏览器地址与端口是否正确（默认 8088）。

② 样式错乱

强制刷新（Ctrl+F5）一次；静态资源带版本号会自动更新。

③ 忘记密码

联系管理员在「用户管理」中重置密码。

④ 数据异常

先从「导入导出」恢复最近备份；必要时从「归档管理」恢复。

⑤ 大屏不更新

刷新数据大屏页面，重新同步文件系统索引。

⑥ 数据安全

所有数据本地存储、不上云；请定期整库备份。
