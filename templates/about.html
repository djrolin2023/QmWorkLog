一、系统简介

本系统是一套面向物业安保、消控等一线岗位的工作台账数字化管理工具，用于按类型与日期记录工作内容并上传现场图片， 支持智能年度 / 周期总结、数据可视化大屏、归档备份与多用户权限管理。所有数据均保存在本地 SQLite 数据库，不上传任何云端， 适合对数据隐私有要求的园区、校区、物业等场景。

二、功能介绍

账

工作台账

按类型与日期记录工作内容与现场图片，模板化录入，规范统一。

智

智能总结

一键生成年度、月度或自定义周期的智能工作总结与统计。

屏

数据大屏

各类型台账数量与趋势可视化，整体情况一目了然。

档

归档管理

按类型归档历史台账，支持下载与一键恢复，数据安全可控。

换

导入导出

支持整库备份、导入与按年 / 类型导出，方便交接与上报。

权

用户管理

多用户体系与密码管理，系统设置集中维护公司与品牌信息。

三、系统特色

图

图片留痕

每条台账可上传现场图片，点击查看原图，工作过程有据可查。

AI

智能总结

基于台账内容自动生成年度 / 周期总结，支持多种总结视角。

屏

可视化大屏

打开即自动同步索引，环形占比、类型分布、月度趋势即时呈现。

档

归档恢复

历史台账按需归档，误删可一键从归档恢复，数据不丢失。

权

权限可控

管理员与普通用户分级，关键操作有日志可追溯。

锁

数据私有

数据全部本地存储，断网可用，隐私可控不上云。

① 数据规模

台账与图片越多占用空间越大，建议定期在「导入导出」中归档与备份。

② 权限

程序默认安装到 D:\QmWorkLog（若计算机无 D 盘，则自动改为 C:\QmWorkLog），运行时仅读写自身目录，无需管理员权限。

③ 网络

系统为纯本地应用，无需联网即可使用；仅「更新与下载」「联系作者」等功能需访问外网。

七、使用方法

  1. 访问系统：浏览器打开系统地址，进入登录页后输入账号密码即可登录。
  2. 登录后台：默认账号 admin / admin（请在正式使用前修改密码）。
  3. 录入台账：在"工作台账"中选择类型与日期，填写内容并上传现场图片后保存。
  4. 智能总结：在"智能总结"中选择类型、年份与周期，一键生成总结报告。
  5. 数据查看：通过"数据大屏"查看各类台账数量与趋势（打开即自动同步）。
  6. 归档备份：在"归档管理 / 导入导出"中定期归档与备份数据。

八、注意事项

① 数据备份

请定期在「导入导出」中执行整库备份，重要数据建议异地留存，避免意外丢失。

② 图片上传

现场图片用于留痕，建议清晰、命名规范；单张过大将影响加载速度。

③ 删除确认

台账、日志等删除操作均有二次确认，批量 / 整类删除请谨慎，必要时先从归档恢复。

④ 账号安全

正式使用前请修改默认 admin 密码；普通用户权限受限，关键操作由管理员执行。

⑤ 索引同步

打开数据大屏时会自动同步文件系统索引，若台账文件被外部改动，刷新大屏即可更新。

⑥ 浏览器缓存

静态资源带版本号自动刷新；如遇样式异常，可强制刷新（Ctrl+F5）一次。

十、更新与下载

本系统的后续版本均通过 GitHub 仓库发布与下载，地址如下：

github.com/djrolin2023/QmWorkLog

更新保护数据：下载更新时，仅覆盖程序代码与静态资源文件，不会更改或删除任何现有数据（数据库 DB/、台账文档 Data/、users.json、config.json 等）。重要变更前建议先通过「导入导出」执行整库备份。

从源码获取 / 拉取更新

如果需要自行构建或从源码运行（如 Linux / macOS 未提供对应安装包时），可通过 Git 拉取仓库：

  1. 获取源码：首次克隆仓库到本地
    git clone https://github.com/djrolin2023/QmWorkLog.git
  2. 安装依赖：进入项目目录，使用 Python 3.10+ 创建虚拟环境并安装依赖
    python -m venv QmWorkLog-venv && QmWorkLog-venv\Scripts\activate
    pip install -r requirements.txt
  3. 拉取更新：已克隆的情况下，进入目录执行
    git pull
    即可获取最新源码；随后重新安装依赖（如有新增）并重新启动。
  4. 启动服务：执行 python app.py，浏览器访问 http://127.0.0.1:8088 即可使用。

① 版本发布

正式安装包（Windows / Linux / macOS）以 GitHub Releases 形式发布，源码更新则合入主分支。

② 数据保护

源码更新同样只替换代码与静态资源，现有数据文件不会被覆盖或删除。
